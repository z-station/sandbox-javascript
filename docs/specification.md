# Спецификация API

- Под кодом программы понимается код на языке программирования JavaScript.
- Код сохраняется во временный файл `main.js`.
- Код выполняется через Node.js командой `node main.js`.
- Формат запроса и ответа: JSON.
- `?` - необязательный параметр запроса.
- `str`, `bool`, `int` - тип данных параметра запроса.

## Эндпоинты

1. [`/health`](health.md) - проверяет, что сервис работает.
2. [`/run`](run.md) - запускает JavaScript-код и возвращает `stdout`, `stderr`, `exit_code`.
3. [`/debug/`](debug.md) - совместимый с примерами endpoint для запуска одной программы.
4. [`/testing/`](testing.md) - совместимый с примерами endpoint для прогона программы на наборе тестов.
