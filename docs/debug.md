## Debug

### Формат запроса:

**Описание:** Выполняет JavaScript-программу через Node.js и возвращает результат ее работы.  
**HTTP-метод:** POST   
**URL:** /debug/  
**Тело запроса:** 

```
{
    "data_in": ?str,
    "code": str
}
```
- data_in - консольный ввод программы (необязательное, может быть null)
- code - код программы

### Формат ответа:

**HTTP-статус ответа:** 200   
**Состояние:** Запрос завершен успешно.  
**Тело ответа:**

```
{
    "result": str | null,
    "error": str | null,
    "exit_code": int
}
```
- result - результат работы программы (null если значения нет)
- error - ошибки выполнения программы (null если значения нет)
- exit_code - код завершения процесса Node.js

**HTTP-статус ответа:** 400    
**Состояние:** Ошибка валидации. Тело запроса не соответствует спецификации.  
**Тело ответа:**
```
{
    "error": str,
    "details": ?str
}
```
- error - текст ошибки
- details - детали ошибки

**HTTP-статус ответа:** 500    
**Состояние:** Внутренняя ошибка.  
**Тело ответа:**
```
{
    "error": str,
    "details": ?str
}
```
- error - текст ошибки
- details - детали ошибки
